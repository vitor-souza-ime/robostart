# RoboStart incremental lessons

Open one numbered `.py` file and press **F5** using the RoboStart launch
configuration while Webots is running with a `Pioneer3at` set to `<extern>`.

`INDEX.csv` lists the exact sequence, learning goal and prerequisites.

- Examples 01–44: Webots-only motion/time/sensors; no extra pip packages.
- Examples 45–49 and 67: optional camera & image display/save.
- Examples 50–66 and 69: optional Ultralytics YOLO11 perception.
- Examples 68 and 70: basic checks and cleanup.

Reset the Webots world before movement scenarios, and terminate the previous
external controller before rerunning F5. All programs use **English method
names**. The initial world need not be included in this package; use your
existing Pioneer3at scene.
